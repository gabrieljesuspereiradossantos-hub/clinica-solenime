# Clínica Solenime — primeira versão

Site institucional inicial para a Clínica Solenime, em Santo André. Construído com Vite, HTML, CSS e JavaScript.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

## Conteúdo a validar

- Procedimentos, indicações e equipe responsável.
- Confirmação do telefone como canal de WhatsApp e agendamento.
- Fotos atuais da clínica com autorização de uso.
- Grafia final da marca, horários e Instagram oficial.
- Revisão da política de privacidade antes de adicionar coleta de dados.

A imagem principal é uma ilustração editorial gerada por IA e está identificada como tal no site. O vídeo no Google Flow e sua sincronização com a rolagem permanecem na etapa de produção audiovisual.

O conceito, as fontes e o storyboard preliminar estão nos documentos Markdown da raiz. O [arquivo Figma](https://www.figma.com/design/LX6FJGSXv8S1Wt3qvMkriC) foi criado, mas a edição ainda depende da liberação da cota MCP do plano.
